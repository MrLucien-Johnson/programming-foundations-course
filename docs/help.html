Quick answers for new learners

These answers are written for people who are new to computers and to this site.

I do not know where my download went.

Look in your Downloads folder. On most computers, you can open Downloads from your file manager.

What is a ZIP file?

A ZIP is a folder that is compressed to save space. Double-click it to open it, then open the folder inside.

How do I open a README file?

A README is a text file. Double-click it and it will open. If it does not, right-click and choose “Open with” then pick a text editor.

Do I need to use Git or the command line?

No. You can learn entirely in the browser. Download the ZIP only when you want to code locally.

A lesson says “unavailable.”

Refresh the page and check your internet connection. Lessons load from GitHub, so a temporary outage can block them. Then return to Courses and open the lesson again.

A quiz will not load or says Partial / Unavailable.

The quiz file may still be publishing, or answers are not ready yet. Try again in a few minutes. You can still keep reading the lesson and come back to the quiz later.

My progress disappeared.

Progress is saved in this browser on this device only. Clearing site data, using private browsing, or switching browsers/devices will look like a fresh start.

Matcher vs advanced courses

The homepage matcher suggests beginner paths (Python, C#, AI). Intermediate and advanced language courses are listed lower on the Courses page once you know the basics.

Reset local progress

This clears lesson completions, quiz results, Start Here steps, and checklist ticks saved in this browser. It cannot be undone.
