Quick answers for new learners

These answers are written for people who are new to computers and to this site.

I do not know where my download went.

Look in your Downloads folder. On most computers, you can open Downloads from your file manager. Prefer a walkthrough? Watch the download tutorial.

What is a ZIP file?

A ZIP is a folder that is compressed to save space. Double-click it to open it, then open the folder inside.

How do I open a README file?

A README is a text file. Double-click it and it will open. If it does not, right-click and choose “Open with” then pick a text editor.

Do I need to use Git or the command line?

No. You can learn entirely in the browser. Download the ZIP only when you want to code locally — see the get-started video. When you install tools, use the Python or C# install videos.

A lesson says “unavailable.”

Refresh the page and check your internet connection. Lessons load from GitHub, so a temporary outage can block them. Then return to Courses and open the lesson again.

A quiz will not load or says Partial / Unavailable.

The quiz file may still be publishing, or answers are not ready yet. Try again in a few minutes. You can still keep reading the lesson and come back to the quiz later.

Why create an account?

Guest mode can keep progress in this browser until you refuse it. Download a backup anytime from Privacy. A free account can sync across devices when the cloud is up, and you can turn on free two-factor authentication. On free hosting, cloud data may reset after a server restart — keep a downloaded backup if that matters. Open Account to try sync, or Support to help fund durable hosting.

How does free 2FA work?

After you sign in on Account, choose Set up 2FA, scan the QR code with an authenticator app, and confirm with a 6-digit code. Save the backup codes shown once. Next sign-in asks for password, then the app code (or one backup code). Full walkthrough: Support → Free 2FA.

How do DevOps & cloud (donor) courses unlock?

Paths for DevOps, AWS, Azure, GCP, Kubernetes, and Terraform sit behind a free account that has donated, or an email the owner allowlists. Create an account, donate via Support, then the owner can grant your email on Account → Donor access. The owner (and PREMIUM_ACCESS_EMAILS) always have access. Beginner language courses stay free for everyone.

The “save progress” banner keeps appearing.

Choose Yes or No once — then it should stop. Change your mind anytime under Account → Device progress settings (or Privacy). If you already had progress saved, the site treats that as Yes so it stops asking.

My progress disappeared.

Guest progress stays only in this browser until you refuse it or clear site data. If browser data is lost, it cannot be recovered unless you import a backup from Privacy or use a cloud account. Cloud accounts on free hosting can also reset after a server restart — keep a downloaded backup if that matters.

Which courses have certificates?

Every course on the site can earn a certificate — beginner tracks and intermediate / advanced language tracks. Open Certificate, pick your course, and print when every tracked module is marked complete.

What is Schools / Corporate / SaaS persona?

Most learners study from home. On Home, Start Here, or Account you can pick Schools & colleges, Corporate L&D, or Self-serve / SaaS builders. That choice only changes tips and emphasis — the same free courses stay available. Clear it anytime or use Reset progress.

How do I continue where I left off?

After you open a lesson or quiz, a Continue banner appears on Home, Courses, Help, and other pages. Guest progress stays in this browser until you refuse it (or clear site data); accounts can sync when the cloud is up.

Is this an official OCR / AQA / Edexcel course?

No — it is an independent path. The skills map to UK GCSE Computer Science programming topics and NCCE / BCS-informed teaching practice. See the Standards map for the full skill table.

Matcher vs advanced courses

The homepage matcher suggests beginner paths (Python, C#, AI). Intermediate and advanced language courses are listed lower on the Courses page once you know the basics.

Can I follow the tutorials in text?

Yes. Each tutorial includes captions in the player and a read-along transcript beside the video. See Tutorials, or open the transcript box on any lesson that has a matching voiceover or setup guide in the course viewer.

Reset local progress

This clears lesson completions, quiz results, Start Here steps, checklist ticks, and “continue where you left off” memory saved in this browser. It cannot be undone.
