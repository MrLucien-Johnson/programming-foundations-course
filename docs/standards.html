Built to exam-board and chartered teaching standards

This course is an independent learning path. It is aligned to the skills expected by major UK GCSE Computer Science boards and by NCCE / BCS computing pedagogy — so what you practice here transfers to school, college, and early career work.

Exam boards we map to

OCR J277 AQA 8525 Edexcel 1CP2 NCCE Teach Computing BCS / Chartered IT

Across boards, programming assessment focuses on the same core craft: design algorithms, write clear code, use sequence / selection / iteration, handle data, and produce robust programs. Our beginner Python and C# paths train that craft with portfolio projects.

Out of scope (and optional stretch)

Board papers also cover theory we do not teach as full modules here — networks, computer systems, and data representation. That is intentional: this site focuses on programming craft.

Curious stretch (not required): binary vs decimal, and how text maps to numbers (ASCII / Unicode). Useful context for GCSE theory papers; not needed to finish the Task Tracker.
