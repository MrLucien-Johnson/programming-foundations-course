How sync works

  • Guest progress stays in this browser’s local storage (most reliable on free hosting).
  • When you sign in, local and cloud progress are merged (completions are combined).
  • While signed in, changes sync when the API is reachable — you can also sync manually.
  • Signing out keeps a copy on this device; cloud updates pause until you sign in again.
