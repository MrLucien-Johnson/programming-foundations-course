[Slide 1] After your first script
After your first script, Module 2 makes programs interactive and useful. You will store values, ask for input, and calculate. These skills power forms, carts, and calculators.

[Slide 2] Variables are labeled boxes
Variables are labeled boxes. Write a name equals a value, for example customer underscore name equals Sarah. Python chooses the type for you, and you can update a variable anytime.

[Slide 3] Talk to the user
Talk to the user with input. Store the answer in a variable, then combine text with f-strings, like hello name.

[Slide 4] Do useful math
Do useful math. Convert text numbers with float or int, calculate price, tax, or wages, and print clear results with f-strings.

[Slide 5] Practice path
Type the examples instead of only reading them. Build the greeting and price calculator exercises, then take the Module 2 quiz when you feel ready.
