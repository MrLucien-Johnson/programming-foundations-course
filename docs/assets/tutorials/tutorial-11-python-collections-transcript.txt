[Slide 1] Today’s lesson goal
Today’s lesson goal: store many values in lists. Look up data with dictionaries. Choose the right collection for the job.

[Slide 2] Lists: ordered collections
Lists are ordered collections. Keep items in order and access by index. Append, remove, and loop through items. Great for playlists, baskets, and queues.

[Slide 3] Dictionaries: keys to values
Dictionaries map a key to a value — like a labelled folder. Use them for fast lookups such as name to email or id to score. Keys must be unique.

[Slide 4] Worked example: contacts
Worked example: keep a list of friend names and a dictionary of name to phone number. Loop the list and print each number from the dictionary.

[Slide 5] Common mistakes
Common mistakes: off-by-one index errors. Assuming a key exists without checking — use get or check first. Mixing up list order with dictionary keys.

[Slide 6] Practice checkpoint
Practice checkpoint: build a tiny shopping list or contact book. Add, print, and look up one item. Then continue in the written Module 5 lesson and quiz.
