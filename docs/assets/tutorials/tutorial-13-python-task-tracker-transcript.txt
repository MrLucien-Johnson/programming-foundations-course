Today’s lesson goal: build a small Task Tracker end to end. Combine variables, decisions, loops, and functions. Ship something you can show on a portfolio.

[Slide 2] Design before you code
Design before you code. List features like add, list, complete, and quit. Decide how tasks are stored. Sketch the menu loop on paper first.

[Slide 3] Core loop pattern
Use a core loop pattern. Show a menu. Read the user’s choice. Run the matching action, then show the menu again.

[Slide 4] Make it robust
Make it robust. Handle empty input and bad menu choices. Confirm before deleting if you add delete. Keep messages clear for beginners testing your app.

[Slide 5] Common mistakes
Common mistakes: building every feature before the menu works. No way to quit the loop. Mixing storage format so list and complete disagree.

Practice checkpoint: get add and list working first. Then add complete and quit. Then continue in the written Module 7 project and acceptance checks.
