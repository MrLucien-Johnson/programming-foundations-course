[Slide 1] Today’s lesson goal
Today’s lesson goal: build a small evaluation set. Score outputs the same way each time. Iterate with evidence, not vibes.

[Slide 2] What good eval looks like
Good evaluation uses ten or more cases — good, bad, and ambiguous. Use a fixed rubric for format, accuracy, and safety. Rerun the same set after each prompt change.

[Slide 3] Worked example
Worked example cases: empty input should refuse politely. A clear ticket should extract fields. Conflicting dates should ask, not invent.

[Slide 4] Practice checkpoint
Practice checkpoint: write five eval cases for your prompt. Score a before and after change. Then continue in the written Module 4 lesson.
