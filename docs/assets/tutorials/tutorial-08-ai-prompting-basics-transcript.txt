[Slide 1] Today’s lesson goal
Today’s lesson goal: turn vague asks into clear prompts. Separate role, task, constraints, and format. Test outputs before you trust them.

[Slide 2] The prompt recipe
Use a prompt recipe. Role: who the model should act as. Goal: what success looks like. Add constraints and an output shape you can check.

[Slide 3] Vague vs specific
Compare vague versus specific. Vague says summarise this meeting. Specific asks for actions, owners, and deadlines as a J S O N list. Specific prompts fail loudly — that is useful.

[Slide 4] Worked rewrite
Worked rewrite: add role project assistant. Require only using the notes provided. Return bullets in the shape action, owner, date.

[Slide 5] Few-shot when it helps
Use a few-shot example when it helps. Show one short correct example close to your real format. Remove examples that teach the wrong pattern.

[Slide 6] Test before you trust
Test before you trust. Try good, empty, and conflicting inputs. Score format, factuality, and helpfulness. Tighten the rules, then retest the same cases.

[Slide 7] Practice checkpoint
Practice checkpoint: rewrite one vague request from your day. Save the before and after in the starter pack. Then continue in the written Prompting Basics lesson.
