[Slide 1] How these modules work
How these intermediate modules work. Each one builds one practical skill. Read the lesson, try the examples, then take the quiz. Keep notes of decisions and tradeoffs.

[Slide 2] Study rhythm
Use a steady study rhythm. Skim goals first. Type along with worked examples. Only then attempt Core and Better exercises.

[Slide 3] When you get stuck
When you get stuck, re-read the common mistakes section. Simplify the input and retry. Open Help or return to the previous module if needed.

[Slide 4] Next step
Next step: open the written lesson for this module. Mark progress as you complete quizzes. Move on when Core exercises pass your own checks.
