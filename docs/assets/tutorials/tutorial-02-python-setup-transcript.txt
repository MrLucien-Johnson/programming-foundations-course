[Slide 1] Install Python
Install Python from python.org slash downloads. On Windows, tick Add Python to PATH before you install. On Mac or Linux, run the installer or use python 3.

[Slide 2] Verify it worked
Verify it worked. Open Terminal or Command Prompt. Run python dash dash version, or python 3 dash dash version. You should see something like Python 3.11 or newer.

[Slide 3] Install a code editor
Install a code editor such as Cursor or Visual Studio Code. Add the Python extension. Then open your python-beginner-workbook folder.

[Slide 4] Your first script
Create hello.py with print Hello. Run python hello.py. Change the message — that is your first real program.

[Slide 5] Python tips
If Windows cannot find Python, reinstall and tick Add to PATH. Use the editor’s integrated terminal. Finish Module 1 exercises, then take the quiz.
