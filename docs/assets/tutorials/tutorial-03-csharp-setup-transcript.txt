[Slide 1] Install the .NET SDK
Install the dot net S D K from dotnet.microsoft.com slash download. Download the latest S D K — version 8 or newer. Run the installer, then finish.

[Slide 2] Verify with the terminal
Open Terminal or Command Prompt. Run dotnet dash dash version. A number like 8 point 0 means you are ready.

[Slide 3] Editor + C# tools
Install Cursor or Visual Studio Code. Add the C sharp Dev Kit extension. Open the csharp-beginner-workbook folder in the editor.

[Slide 4] Create and run a console app
Create a console app with dotnet new console. Move into the folder with cd. Run dotnet run, then edit Program.cs to make it yours.

[Slide 5] C# tips
Remember: C sharp is the language. Dot net is the toolbox. Open the whole project folder, finish Module 1, then take the quiz.
