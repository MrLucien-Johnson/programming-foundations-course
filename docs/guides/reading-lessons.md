# Reading Lessons & Stretch Guides

Every module ends with learning work you do here. **Stretch Resources** are optional deeper reading.

## What changed

Stretch Resources used to link out to external documentation sites. Those links pulled learners away from Programming Foundations.

Now Stretch Resources point to **our Guides** — first-party documentation hosted on this site.

## How to use Stretch Resources

1. Finish the module exercises and checklist first.
2. Open the linked guide in the Guides viewer.
3. Skim the sections that match what you struggled with.
4. Return to the course and start the next module.

## Guides hub

## Tip

If a guide links to a course module, that module is also on this site — use those links to keep learning in one place.
