How progress works (guest vs account)

You never need to donate — or create an account — to learn. Here is what stays where.

  • Guest (no account): progress can stay in this browser until you refuse it. If browser data is cleared or lost, that progress cannot be recovered unless you have a downloaded backup or you rebuild it.
  • Free account: progress can sync to the cloud when the API is up, so you can continue on another device. On free hosting, cloud data may still reset after a server restart — keep a guest backup if that matters.
  • Backups: download or import a JSON progress file anytime from Account or Privacy.

Free two-factor authentication (2FA)

Cloud accounts can turn on free authenticator-app 2FA. No paid plan — it is part of a normal free account when the cloud API is working.

How it works

  1. Sign in on Account, then open Two-factor authentication.
  2. Tap Set up 2FA. Scan the QR code with an authenticator app (Google Authenticator, Authy, Microsoft Authenticator, or similar), or type the secret manually.
  3. Enter the 6-digit code from the app to confirm. You will see backup codes once — save them somewhere safe.
  4. Next sign-in: enter email + password, then the current app code (or one unused backup code).

Useful to know

  • 2FA protects the account password step — it does not replace a strong password.
  • Each backup code works once. If you use one, the others still work until you turn 2FA off or set it up again.
  • Lost your phone and your backup codes? You will not be able to sign in until support can help verify ownership — message Instagram and keep future backup codes safe.
  • Turn 2FA off anytime on Account with your password plus a current app or backup code.
  • Guest learning never needs 2FA. 2FA only applies after you create and use a cloud account.
